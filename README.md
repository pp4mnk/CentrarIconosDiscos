**English**

This script automatically centers the desktop drive icons in EasyOS and raises them above the dock so they do not overlap it. It adjusts their position to your screen width and the number of drive icons, with 68 pixels between them.

It backs up the original configuration before making changes. To apply the new layout:

1. Open **Menu > Desktop > Desktop drive icon manager**.
2. Tick **Erase then redraw and realign existing icons**.
3. Click **OK**.
4. Save your work and **Restart X**.

**Español**

Este script centra automáticamente los iconos de las unidades en el escritorio de EasyOS y los eleva para que no se superpongan al dock. Ajusta su posición según el ancho de la pantalla y la cantidad de iconos, dejando 68 píxeles entre ellos.

Antes de realizar los cambios, guarda una copia de seguridad de la configuración original. Para aplicar la nueva distribución:

1. Abre **Menu > Desktop > Desktop drive icon manager**.
2. Marca **Erase then redraw and realign existing icons**.
3. Pulsa **OK**.
4. Guarda tu trabajo y **reinicia X (Restart X)**.
